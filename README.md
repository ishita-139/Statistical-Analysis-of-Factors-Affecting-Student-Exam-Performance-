# Statistical-Analysis-of-Factors-Affecting-Student-Exam-Performance-
Academic performance of students is influenced by multiple behavioral, environmental, and 
personal factors. This study analyzes the factors affecting student academic performance using 
data analysis and machine learning techniques. The dataset contains various attributes such as 
age, study hours, social media usage, attendance percentage, sleep hours, diet quality, parental 
education level, and exam scores. 
Exploratory Data Analysis (EDA) techniques including histograms, scatter plots, and correlation 
heatmaps were applied to understand data distribution and relationships between variables. Data 
preprocessing steps such as handling missing values, encoding categorical variables, and feature 
scaling were performed to prepare the dataset for modeling. 
Multiple machine learning regression models including Linear Regression, Decision Tree, 
Random Forest, AdaBoost, and XGBoost were implemented to predict student exam scores. The 
performance of these models was evaluated using metrics such as R² score and Root Mean 
Squared Error (RMSE). 
The results indicate that study hours and attendance positively influence exam performance, 
while excessive social media usage negatively impacts academic outcomes. Among the models, 
Linear Regression and XGBoost demonstrated strong predictive performance. This study 
highlights the importance of lifestyle and behavioral factors in determining academic success and 
demonstrates the effectiveness of machine learning models in predicting student performance.
